# Migration history

These two files record how the legacy thesis working directory was ported
into this repository layout. Newcomers do not need them: start at the
[top README](../../README.md) and [`docs/GETTING_STARTED.md`](../GETTING_STARTED.md).

- [`REFACTOR_SPEC.md`](REFACTOR_SPEC.md) — the as-built layout, packages,
  config and commands, the numbered decisions cited elsewhere in the repository,
  and the legacy-to-port map of every archived script.
- [`PORT_NOTES.md`](PORT_NOTES.md) — legacy behaviours kept or fixed on
  migration, how each port was checked, one section per area.

What changes or disagrees with a published result is in
[`docs/KNOWN_ISSUES.md`](../KNOWN_ISSUES.md).
