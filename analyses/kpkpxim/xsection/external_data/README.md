# External data

`Clas_data.csv` — published CLAS total cross section for γp → K⁺K⁺Ξ⁻ used for
comparison in `PlotTotXsecWithClas.C`. Columns: E_γ (GeV), σ (nb or arbitrary
units matching the plot's y-axis), σ uncertainty.

Source: CLAS (publication to be cited by the author). Neither the macro's
comments nor the CSV file carry a citation for the source publication.
